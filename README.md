# کاتب (Kāteb)

مجلس‌نویسِ خودکار — صوتِ مجلس را با **NotebookLM** رونویسی و با **Gemini** تمیز می‌کند و
سندِ فارسیِ ساختارمند (`.docx` / `.md`) روی سیستمِ خودت می‌سازد. کاملاً **مرورگری** —
بدونِ کلیدِ API. فقط یک‌بار ورود با گوگل.

## اجرا (حالتِ توسعه)

```bash
cd kateb
npm install                 # وابستگی‌ها + دانلودِ Chromiumِ Playwright
npm start                   # اجرای اپ
```

بارِ اول یک پنجرهٔ Chromium برای ورود به گوگل باز می‌شود؛ لاگین در پروفایلِ اپ ذخیره می‌ماند.

## نصب‌کننده‌ها

- **لینوکس:** `dist/Kateb-0.1.0.AppImage` آماده است — دابل‌کلیک کن، اجرا می‌شود.
- **ویندوز (exe دابل‌کلیکی) و مک (dmg):** روی همان سیستم‌عامل یا خودکار با **GitHub Actions**
  ساخته می‌شوند. راهنمای کامل در [`BUILD.md`](BUILD.md). (از لینوکس نمی‌شود ویندوز/مک ساخت.)

## تست

```bash
npm test          # هستهٔ منطقی (chunk، حلقهٔ ضدِ خلاصه، ساختِ docx/md)
npm run test:e2e  # اتوماسیونِ NLM+Gemini روی fixture (headless)
npm run test:orch # کلِ پایپ‌لاین روی fixture (prepare→transcribe→clean→build)
node test/parallel.js   # پردازشِ موازیِ چند فایل
```

`test/fixtures/server.js` یک NotebookLM و Gemini‌ِ قلابی است که DOMِ واقعی را تقلید
می‌کند (و برای متنِ بلند عمداً خلاصه می‌دهد) تا کلِ اتوماسیون — از جمله **بازیابی از
خلاصه‌سازی** — بدونِ حسابِ گوگل تست شود.

## وضعیت

- ✅ **E2E واقعی پاس شد** — یک فایلِ واقعی از ابتدا تا انتها (NLM + Gemini) به `.docx`/`.md` تبدیل شد
- ✅ NLM (ساخت/آپلود/رونویسی/استخراج) و Gemini (paste/تمیزکاری) هرکدام با **سرویسِ واقعی** تست شدند
- ✅ هستهٔ منطقی + حلقهٔ ضدِ خلاصه‌سازی + **پردازشِ موازی**، همه تست‌شده
- ✅ AppImage لینوکس build و بوت شد؛ ویندوز/مک با GitHub Actions ([`BUILD.md`](BUILD.md))

## نقشهٔ کد

```
src/main/
  main.js            پنجرهٔ Electron + IPC
  preload.js         پلِ امنِ UI ↔ main
  config.js          تنظیمات (JSON در userData)
  selectors.js       تمام دانشِ DOM برای NLM و Gemini (قابلِ آپدیت)
  pipeline/
    orchestrator.js  موتور: صف، مراحل، رویدادهای پیشرفت
    browser.js       Playwright + پروفایلِ ماندگار + تشخیصِ لاگین/چالش
    notebooklm.js    ساخت/آپلود/انتظار/استخراجِ NLM
    gemini.js        تزریق/ارسال/استخراجِ Gemini
    verify.js        حلقهٔ ضدِ خلاصه‌سازی (۳ چک + retry + resplit + دروازه)
    audio.js         شکستن و re-encode صوت با ffmpeg
    chunk.js         تقسیمِ رونویسی
    output.js        ساختِ docx راست‌به‌چپ + md
    prompt.js        پرامپتِ پیش‌فرضِ حفظِ لحن + سازندهٔ پیام
src/renderer/        رابطِ کاربریِ فارسیِ RTL (۴ صفحه)
```

## یادداشت‌ها

- **بدونِ خلاصه‌سازی:** هر تکه بعد از تمیزکاری سه بررسی می‌شود (طول / پوششِ انتها / عباراتِ
  خلاصه‌ساز)؛ ناقص → دوباره → نصف‌کردن. اگر تکه‌ای ترمیم نشد، به‌جای سندِ خلاصه‌شده به کاربر هشدار می‌دهد.
- **صوتِ بلند/حجیم:** بزرگ‌تر از حدِ حجم (پیش‌فرض ۴۵MB) پیش از آپلود مونو/کم‌حجم می‌شود؛
  بلندتر از حدِ زمان (پیش‌فرض ۱۵۰ دقیقه) خودکار شکسته می‌شود؛ اگر NLM روی تکه‌ای گیر کند،
  با `re-encode`ِ مونو دوباره تلاش می‌شود.
- **پس‌زمینه (headless):** پیش‌فرض نامرئی اجرا می‌شود تا سیستمت آزاد بماند؛ فقط برای ورودِ
  اولیه، در تنظیمات «نمایشِ مرورگر» را روشن کن.
- **موازی:** چند فایل هم‌زمان جلو می‌روند (پیش‌فرض ۲؛ در تنظیمات قابلِ تغییر). تمیزکاریِ
  Gemini سریال است چون کلیپ‌بورد مشترک است.
- **ری‌ترای:** اگر فایلی خطا خورد، دکمهٔ «↻ از اول» روی همان کارت آن را ریست و دوباره اجرا
  می‌کند — بدونِ بستن و باز کردنِ اپ.
- **نگه‌داری:** اگر گوگل ظاهرِ NLM/Gemini را عوض کند، فقط `selectors.js` به‌روزرسانی می‌شود.
